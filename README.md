# Fogón de Luna — Landing de demostración

Página de demostración de una landing page para un **restaurante ficticio** en Barranco, Lima, Perú.

**Fogón de Luna no es un restaurante real.** Esta página sirve para mostrar a negocios locales (restaurantes, clínicas y tiendas) cómo puede verse una landing mobile-first, con pedido por WhatsApp, carta, mapa, Yape/Plin y testimonios de ejemplo.

## Contenido

- Diseño mobile-first
- Botón de WhatsApp con mensaje prellenado (número de demostración)
- Carta con precios en soles
- Ubicación en Barranco (dirección ficticia) y mapa de Google
- Mención de Yape y Plin
- Testimonios claramente marcados como ejemplo

## Desarrollo local

Abre `index.html` en el navegador, o sirve la carpeta:

```bash
npx serve .
```
